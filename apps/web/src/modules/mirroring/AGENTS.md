# 新版镜像采集模块

- 仅在 Next.js 服务端运行，不向浏览器暴露源站账号、Cookie、机器人接口密钥。
- source 负责登录、限流、重试、短期内存缓存和结构校验；collection 只扫描并保存采集进度。
- planning 将源站文章转换为幂等原子任务；禁止在采集阶段直接写入 threads/replies。
- publishing 通过机器人发布接口调用事务业务服务，正文、去重回执、通知必须原子提交。
- scheduling 使用 PostgreSQL 租约与持久状态协调多进程；进度保存以已落地任务为准，不以源站回复总数代替。
- 新实现不得调用历史全量导入链路，也不得删除或重建历史镜像内容。
- 源站文章 ID 是去重依据，楼层仅作展示与旧数据兼容参考。
- 文档使用中文；测试使用模拟数据，真实源站测试必须低频且只读。
