# 私有访问与部署

## 访问边界

- 未登录访问首页、内容页、管理页、API 和静态资源，统一返回纯文本 HTTP 404。
- 404 不包含登录链接、认证提示或 Location 响应头；响应禁止缓存和搜索索引。
- 登录入口与 OAuth 回调精确放行，不把整个认证目录、注册或 setup 接口公开。
- 登录成功后可正常访问根路径首页。会话失效时不自动引导登录。
- Web 会话由 Kinde SDK 验证，并保留其刷新 Cookie 的能力。移动端公开 API 接受经过签名、issuer 和 audience 验证的 Bearer token。
- 管理员身份限制仍由现有页面和 API 守卫执行。

## 当前运行服务

- Dokploy 项目仅保留 frontend 和 new database。
- 自动采集保持关闭：`WEB_SCHEDULER_ENABLED=false`、`WEB_SCHEDULER_RUN_ON_BOOT=false`。
- Python 采集服务、两个 Redis 和旧数据库退役，前端删除旧数据库及采集服务连接配置。
- 旧库删除前保存 PostgreSQL 自定义格式备份，后续恢复应通过 pg_restore 导入隔离数据库。
- 新版采集将放在 Next.js 服务端，但仍走机器人发帖/回复业务链路；本次不实现采集重构。
